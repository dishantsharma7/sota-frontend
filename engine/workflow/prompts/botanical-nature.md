# Style seed: Botanical (Nature)

> Source family: taste-skill §2.B organic · impeccable mode: read · dials 5/4/3

## Design Read
Wellness/nature/eco-friendly brand site — botanicals, leaf shapes, organic
curves, muted greens + cream, airy layout. Calm and grounded: nature as the
visual system, plants as the actual texture.

## Dials
- variance: 5 · motion: 4 · density: 3

## System
- **System:** custom. Tailwind v4 + organic SVG leaf/arch shapes as dividers.
- **Type:** warm humanist sans + optional italic serif for pull lines (NOT
  Fraunces/Instrument Serif) — one pairing max.
- **Color:** cream/paper base + deep forest-green ink + ONE botanical accent
  (sage, moss, or terracotta). Green-forward, but green is not the only color.
- **Radius:** organic — 18–24px leaf-like curves; arched image crops, one scale.
- **Texture:** real botanical photography (or credible illustration), paper grain,
  flat leaf shadows — no glass.

## Motion (emil bar)
- Scroll: gentle reveal (fade + 12px, 300ms), sections only; leaves may sway once
  (rotate 1deg, 800ms) on scroll-into-view — one moment per page.
- Hover: image crops scale 1.02 + caption underline, 200ms.
- Reduced motion: static leaves, content visible.

## Bans
Gradients, neon green, glass, floating shadows, purple, uncurated stock nature
photos, animation on body text, emoji.
