# Style seed: Claymorphism (Soft 3D)

> Source family: taste-skill §2.B clay aesthetic (labeled approximation) · impeccable mode: persuade · dials 5/5/4

## Design Read
Consumer/app landing with soft 3D clay shapes — puffy rounded forms, soft
two-layer shadows, consistent top-light, friendly palettes. Honest label in code
comments: a morph of the glassmorphism trend's cousin; keep one light source and
the contrast floor intact.

## Dials
- variance: 5 · motion: 5 · density: 4

## System
- **System:** custom. Native CSS/Tailwind; clay forms via layered border-radius +
  2 stacked soft shadows (top-light: highlight top-left, deep shadow bottom-right).
- **Type:** rounded friendly sans (Nunito / Baloo direction), one family, medium
  weights.
- **Color:** soft pastel base (cream, blush, sky) + ink + 1–2 saturated accents for
  CTAs — pastels for surfaces, saturated for action.
- **Radius:** blob-like (24–32px) clay forms, pill buttons — generous.
- **Texture:** matte fills; NO glossy highlights (a clay object is dull).

## Motion (emil bar)
- Press: clay form presses INTO the page (translate 2px + shadow collapse), 120ms —
  tactile and physical.
- Entrances: soft rise (translateY + fade, 300ms), spring bounce ≤ 0.2.
- No blur, no parallax, no marquees.
- Reduced motion: instant states, static forms, content visible.

## Bans
Gradients, glossy/specular highlights, glass, purple, full-page clay (use on
cards/CTAs only — backgrounds stay flat), shadows without a consistent light
source, emoji.
