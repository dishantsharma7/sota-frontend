# Style seed: Brutalist Dev Portfolio

> Source family: taste-skill `brutalist-skill` · impeccable mode: experience · dials 9/8/3

## Design Read
Creative-developer portfolio, brutalist language — raw HTML honesty, no ornament,
type as the interface. Native CSS, custom type, monospace labels.

## Dials
- variance: 9 · motion: 8 · density: 3

## System
- **System:** custom — no library chrome. Tailwind v4 utilities + native CSS.
- **Type:** grotesque display (Geist / Space Grotesk direction) + mono for metadata.
- **Color:** near-black + bone + ONE raw accent (signal orange, safety yellow, or electric lime — pick one, lock it).
- **Radius:** sharp (0). Thick hard borders (1–2px, full-opacity). No shadows, or hard offset shadows only.
- **Texture:** grain / scanline / grid overlays kept at 5–10% opacity. ASCII or mono labels as navigation.

## Motion (emil bar)
- Kinetic type (SplitText per-line reveals on scroll) — the signature move.
- Marquee strips for skills/credits (linear, off-main-thread CSS).
- Hover: hard border color shifts + translate, 100–160ms, no blur/glow.
- Scroll: GSAP ScrollTrigger pinning for 1–2 showcase sections max. Lenis for feel.

## Bans
Centered hero, cards-with-shadows-everywhere, glassmorphism, gradients, emoji.
