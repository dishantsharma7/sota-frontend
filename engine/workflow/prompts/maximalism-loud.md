# Style seed: Maximalism (Loud)

> Source family: taste-skill §1.C high-density presets · impeccable mode: experience · dials 9/8/8

## Design Read
Festival/e-commerce/culture sites where more is more — layered type, dense
pattern, saturated color blocks, collage energy. Maximalism done deliberately:
EVERY element earns its density; hierarchy still leads the eye.

## Dials
- variance: 9 · motion: 8 · density: 8

## System
- **System:** custom. Native CSS/Tailwind + collage layering (positioned elements,
  overlapping panels).
- **Type:** 2–3 families MAX with explicit roles (display / accent / mono) — the
  game IS multiplicity, but the ROLES are fixed.
- **Color:** ink + paper + 3–5 saturated accents as flat fills/blocks. Explicit
  palette lock in DESIGN.md (deviation from the one-accent rule must be justified
  per accent).
- **Radius:** mixed but documented: sharp for type blocks, pill for CTAs.
- **Texture:** flat patterns (dots/stripes/checker), stickers, stamps, price tags,
  editorial chaos — bounded per section.

## Motion (emil bar)
- Section entrances slam/pop (overshoot springs, motion/react), transform+opacity
  only, 300–450ms.
- Hover: elements shift/rotate ±1–2deg + color swap, 150ms.
- Marquee strips (2 max) for announcements.
- Reduced motion: collage assembles statically; text never hidden.

## Bans
Noise-without-hierarchy, gradients (flat fills only), purple, glass, more than
one animation per viewport, unreadable background text, emoji-as-content (stamps
are shapes, not emoji).
