# Style seed: Swiss Minimalist

> Source family: taste-skill core (§1.C low-variance presets) · impeccable mode: persuade · dials 5/3/3

## Design Read
Architecture/design-agency/product site in the International Typographic Style —
strict grid, grotesque type, strong hierarchy, one accent, layout as a system of
rules. Calm authority; everything is justified by the grid.

## Dials
- variance: 5 · motion: 3 · density: 3

## System
- **System:** custom. Tailwind v4 + a strict visible grid discipline (taste-skill §4.7).
- **Type:** grotesque sans (Archivo / Space Grotesk direction — NOT Inter), tight
  uppercase tracking for labels, controlled display sizes.
- **Color:** white/off-white + near-black + ONE accent (International Orange or
  cobalt — the classic Swiss move). Accent is a pointer, never a wash.
- **Radius:** sharp (0). 1px rules, full-height columns, generous whitespace.
- **Texture:** bare — no texture. Whitespace is the material.

## Motion (emil bar)
- Minimal: sparse section reveals only if needed (fade + 4px, 200ms), no bounce.
- Hover: rule/underline grows + accent switch, 150ms.
- Nothing scroll-anchored; no marquee; no transforms on the grid itself.
- Reduced motion: static, content visible.

## Bans
Decorative chaos, multiple typefaces, shadows, gradients, glass, over-animation,
asymmetry without a reason, emoji, centered-everything.
