# Style seed: Newsprint Editorial

> Source family: taste-skill §2.B editorial · impeccable mode: read · dials 7/3/2

## Design Read
Newspaper/magazine site for blogs, journals, editorial outlets — multi-column
grid, paper texture, drop caps, bylines, pull-quotes, folio numbers, serif body
text. Content-first; the layout IS the design.

## Dials
- variance: 7 · motion: 3 · density: 2

## System
- **System:** custom. CSS Grid with explicit column spans (2–3 col body, wider
  feature columns) — no 12-col symmetry default.
- **Type:** serif body stack at 17–19px, display serif for headlines (NOT
  Fraunces/Instrument Serif; e.g. a Newsreader-family direction), italic emphasis
  in-family; mono folios.
- **Color:** newsprint paper (#F4F1EA) + ink (#1A1A1A) + ONE editorial accent (deep
  red or cobalt) for links and rules only.
- **Radius:** sharp (0). Hairline rules separate sections; column rules where authentic.
- **Texture:** paper grain 3–5% opacity, drop caps, pull-quotes as full-width type
  moments, numbered sections in mono.

## Motion (emil bar)
- Almost none: scroll reveal only for long-form section markers (fade + 8px,
  200ms); the page stays still — a newspaper doesn't bounce.
- Hover: link underline expands + accent color, 150ms.
- No parallax, no marquees, no scroll-jacking.
- Reduced motion: n/a — already static.

## Bans
Motion everywhere, cards-as-everything, gradients, perfect symmetry (asymmetry is
the point), blur, emoji, hover effects on body copy.
