# Style seed: Premium Dark Tech

> Source family: taste-skill §2.B dark tech · impeccable mode: persuade · dials 8/7/4

## Design Read
AI / devtools product landing for technical buyers — dark, precise, engineered.
Terminal motifs, mono accents, one electric accent. Trust through specificity, not hype.

## Dials
- variance: 8 · motion: 7 · density: 4

## System
- **System:** custom + shadcn/ui primitives (heavily customized — never default state).
- **Type:** Geist + Geist Mono pairing. Display tracking-tight, mono for code/eyebrows.
- **Color:** deep near-black base (#0a0a0a family), zinc grays, ONE electric accent
  (emerald, electric blue, or amber — not purple).
- **Radius:** soft (12px) for interactive; sharp for code blocks. Locked scale.
- **Texture:** terminal/code motifs, subtle grid, console-style status lines.

## Motion (emil bar)
- Hero: code-typing or data-stream effect (rare, first-time delight budget).
- Feature sections: scroll-triggered reveal, transform+opacity, ease-out, <300ms.
- Hover: accent border + 1px translate, 100–160ms.
- Command palette / modal: 150–250ms ease-out, transform-origin at trigger.

## Bans
AI-purple glow, glassmorphism-on-everything, floating gradient orbs, Inter default, emoji.
