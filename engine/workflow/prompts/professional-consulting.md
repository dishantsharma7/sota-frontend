# Style seed: Professional (Consulting)

> Source family: taste-skill §2.A-adjacent (no official package — clean custom) · impeccable mode: persuade · dials 3/3/3

## Design Read
Consulting/legal/finance firm site — calm, credible, specific. Trust through
explicit methodology, team, and track record; quiet typography, strong
information architecture, zero decoration.

## Dials
- variance: 3 · motion: 3 · density: 3

## System
- **System:** custom + shadcn/ui primitives. Tailwind v4.
- **Type:** professional sans (Archivo direction — NOT Inter), 16px body, sans
  display; mono optional for figures.
- **Color:** white/off-white + ink + ONE restrained accent (navy, deep green, or
  oxblood). Accent for links/CTAs only.
- **Radius:** soft (8px), restrained; sharp edges for document-style content.
- **Texture:** bare. Rules and whitespace; document-preview cards carry real
  metadata, never placeholders.

## Motion (emil bar)
- Nearly none: hover = link underline + accent, 150ms; accordions 200ms ease-out.
- No entrance choreography, no parallax — stillness is the aesthetic.
- Reduced motion: n/a — already static.

## Bans
Decorative type, gradients, glass, statistics without sources,
stock-photo-of-handshake, generic testimonial photos, "we're a family" copy
without substance, emoji.
